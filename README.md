# RaceDayAPI

RaceDayAPI is an ASP.NET Core Web API developed for managing race events.

## Features

- User Registration & Login
- JWT Authentication
- Organizers
- Participants
- Events
- Categories
- Race Routes
- Weather Information
- Event Enrollments
- Race Results
- Entity Framework Core
- SQL Server
- Swagger UI
- Unit Testing with xUnit

## Technologies

- ASP.NET Core Web API
- Entity Framework Core
- SQL Server LocalDB
- JWT Authentication
- BCrypt Password Hashing
- Swagger
- xUnit
